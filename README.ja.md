# Train ReDoor

[English（主文書）](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Cities: Skylines II の対応列車で使う共通スライドドアコントローラーです。ゲームの左右の乗降信号に従ってドアを開閉します。車両モデルは別途導入します。

- Mod バージョン：**1.2.0**。アセンブリ：**1.2.0.0**。
- 推奨ゲーム版：**1.6.***。記録されたビルド環境：**1.6.2f1**。
- [Paradox Mods — ID 164831](https://mods.paradoxplaza.com/mods/164831/Windows)。

## プレイヤー

本 Mod と Train ReDoor 対応車両を同じプレイセットに追加して有効にし、プレイセット変更後はゲームを再起動します。路線で運行すると、乗降時にホーム側のドアが開閉します。

手動導入には実行用 ZIP を使い、TrainReDoor フォルダーを実際のゲームユーザーデータ内の Mods に配置します。ソース ZIP は開発用です。同じドアを操作するコントローラーの重複を避けてください。[導入方法](docs/INSTALL.md)。本 Mod だけで全車両に可動ドアが追加されるわけではありません。

## 制作者

公共の ReDoor/TrainReDoor 命名規則、または既存ボーン名への JSON マッピングを使います。独立ガラスを含む可動部を正しくスキニングします。実際のホーム側はインポート後のゲーム座標 X で判定します。

## 開発と検証

公式 Modding Toolchain と .NET SDK を用意し、scripts/Build.ps1、Test.ps1、Validate.ps1、Package.ps1 を順に実行します。通常の処理は工程内に出力し、インストール済み Mod の置換やアップロードは行いません。[ビルドと公開準備](docs/DEVELOPMENT.ja.md)。

平行移動式の引き戸のみ対応します。回転、多段階プラグドア、音、衝突、発車インターロック、乗客経路は含みません。静的プレビューには乗降信号がありません。車両ごとの JSON 自動検出は未実装です。

ローカル記録では 2026-10-25 に 1.2.0 のアップロードが成功しています。コード・合成ケースのテストとゲーム内検証は区別して記録します。ゲーム内乗降と購読版の動作検証は未記録であり、1.6 系の全パッチを検証したという意味ではありません。[検証状況](docs/VALIDATION.md)。
