# Contributing

English is the primary language for source comments, public logs and documentation. Add Japanese translations immediately after meaningful English comments, using EN/JA labels in code. Keep identifiers, JSON keys and diagnostic messages stable and in English. Chinese documentation may be maintained as an additional translation.

Use generic train examples and public bone conventions. Do not add brand/vehicle-name whitelists, personal workflow history, private paths or game binaries. Label synthetic fixtures as synthetic and never describe them as imported model or gameplay evidence.

Run official build/post-processing, tests, local validation and packaging. Changes to boarding, axes or timing also require separately recorded gameplay checks. Contributions use the project's MIT license.

日本語：ソースコメント・ログ・主文書は英語を優先し、意味のあるコメントの直後に日本語を追加してください。識別子と JSON キーは英語のまま維持します。汎用の例を使用し、合成ケースを実モデル検証と表現しないでください。


For this repository, keep Private visibility. The maintainer reviews Markdown, configuration, scripts and source text before the initial push. Keep the reviewed file manifest with the local publication record.

中文：仓库保持 Private；首次推送前审阅 Markdown、配置、脚本和源码文本，按本地文件清单确认实际上传范围。英文为主，日文其次，中文第三。
