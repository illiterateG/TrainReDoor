# Train ReDoor

Animated sliding doors for compatible trains in Cities: Skylines II.

## How to use

1. Add Train ReDoor and a train asset that supports it to the same playset.
2. Enable both and restart the game after changing your playset.
3. Run the train on a line. During boarding, the doors open on the platform side and close when boarding ends.

## What you need

This mod is a shared door controller. Train models are downloaded separately, and the train asset must support Train ReDoor. Installing this mod alone does not add moving doors to every train.

Use only one installed copy of Train ReDoor. If another mod controls the same train's doors, avoid enabling both controllers at the same time.

Recommended game versions: **1.6.***
