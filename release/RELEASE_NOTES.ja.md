# Train ReDoor 1.2.1

メッシュごとに同一の `Bound` ログをセッション内で一度だけ記録します。ドアボーンの数が同じでも、側や移動量、ボーンインデックスが変われば新しい構成を記録します。

Cities: Skylines II 1.6.4f1 で公式ビルドと自動テストが成功しました。計測用ビルドは同じセーブで動作確認しました。重複ログは成果物 DLL の回帰テストで確認し、エディターでの再インポート比較は未確認です。

手動導入には `TrainReDoor_1.2.1.zip` をダウンロードし、[導入手順](../docs/INSTALL.md)を参照してください。
