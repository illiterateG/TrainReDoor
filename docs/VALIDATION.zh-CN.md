- [ ] 检查门板／玻璃同步、上下客结束后的关门、暂停／恢复。
- [ ] 有可复现场景时测试双侧独立上下客；否则保持未测。
- [ ] 检查无关骨骼和车包、保存重载及重启。
- [ ] 实际查看多视角的形状、蒙皮、法线、材质和玻璃。
