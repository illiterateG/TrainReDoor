# 安装与升级

1. 退出游戏。下载 Release 附件中的运行时 ZIP，不是自动生成的 Source code.zip。
2. 确定实际游戏用户数据目录。默认通常为 `%USERPROFILE%/AppData/LocalLow/Colossal Order/Cities Skylines II/`，自定义 userDataPath 会改变位置。
3. 解压到该目录的 `Mods/`，得到 `Mods/TrainReDoor/TrainReDoor.dll` 和旁边的 `TrainReDoor.json`。不要多套一层 TrainReDoor，也不要复制到游戏 Managed 文件夹。
5. 启动游戏，在当前播放集启用控制器和兼容车包。按作者教程在线路上检查。

当前没有公开 Paradox Mod ID。未来订阅版发布后，先移出本地副本再启用订阅版。通过平台更新时，手工修改的插件旁 JSON 可能被替换，先在扫描目录之外备份。优先使用自动命名车包。
